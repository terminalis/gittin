01

Every save, in git.

In a folder that's a git repository, saving also commits, with a message that says what changed. Version history lists each file's commits.

  • Git is built in, so there's nothing else to install
  • Start a repository to give any folder git history

02

Sync with GitHub.

Sign in to GitHub to clone, sync and publish your repositories.

  • Your files go to GitHub only when you sync or publish
  • Gittin asks you to sign in only when GitHub needs it

03

Write, then preview.

Format Markdown with the toolbar you already know. Switch to Preview to read the finished page.

  • Tables, maths, diagrams and emoji render in Preview
  • Preview never changes your source

04

More than Markdown.

Notes, code and config open just as easily, each with its own syntax colours.

  • Plain text, JSON, YAML, HTML, CSS, JavaScript and TypeScript
  • Any other text file opens as plain text

05

Bring the whole folder.

Open a folder, find the file you need and save each one straight back where it came from.

  • Unsaved changes wait until you save
  • A dot marks files with unsaved changes

06

Nothing gets lost.

Diff shows what changed since you last saved. Version history keeps your recent saves, so you can compare or restore them.

  • Up to 20 recent saves of each file, kept on your device
  • Your file only changes when you save

A few things to know

Do I need an account?
No. Gittin has no accounts of its own; the desktop app can sign in to GitHub to sync repositories.
Where are unsaved changes kept?
On this device, in the desktop app or your browser, until you save. A browser can clear its storage, so save to keep them in a file.
Does Preview change my Markdown?
No. Preview is read-only and shows source snippets for anything it can't render fully. Switching views leaves your source and undo history unchanged.
Can I work offline?
Yes. The desktop app works offline from the start. In a browser, Gittin starts without a connection once it has loaded on this device.
