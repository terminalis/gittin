Install Gittin

Get the desktop app, with git and GitHub, or install the web version from your browser.

Windows

Desktop app

Windows 10 (version 1903 or later) or Windows 11, 64-bit. Updates come through the Microsoft Store.

Get it from Microsoft Store

Linux

Desktop app

64-bit (x86_64), as a Flatpak. Updates come through your software centre or flatpak update.

Download Flatpak

Or in a terminal:
flatpak install --user https://terminalis.github.io/packages/flatpak/gittin.flatpakref

Web version

Gittin in its own window, from your browser. Works on any device.

On a Mac, iPhone, iPad or Android, install the web version.

In Safari, choose File › Add to Dock.

In Safari, tap Share, then Add to Home Screen.

Your browser can't install Gittin, but you can use it here.
